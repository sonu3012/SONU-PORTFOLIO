## ⚡ Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/sonu3012/sonu-portfolio.git
cd sonu-portfolio

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the app
python app.py
```

Then open **http://127.0.0.1:5000** in your browser.

## 🎨 Customise

| I want to change | Edit this |
|:---|:---|
| Name, about, skills, projects, experience, certificates | `data.py` |
| Profile photo | `static/img/profile.png` |
| Resume PDF | `static/` folder |
| Colours, fonts, layout | `static/css/style.css` |

<br/>

## ☁️ Deployment

Deployed on **Render** with these settings:

| Setting | Value |
|:---|:---|
| Build Command | `pip install -r requirements.txt` |
| Start Command | `gunicorn app:app` |

Every `git push` to the `main` branch redeploys the site automatically.
